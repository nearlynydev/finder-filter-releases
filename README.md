# Finder Filter releases

Native macOS companion for Finder: filter a folder using filename patterns or regular expressions, optionally search recursively, and keep familiar Finder-style file operations and views.

Requires macOS 14 or later. Universal build for Apple silicon and Intel.

## Downloads

Download the ZIP from [Releases](https://github.com/nearlynydev/finder-filter-releases/releases), extract it and install Finder Filter.app in Applications.

The application is Developer ID signed. The current build is not notarized by Apple.

Enable the Finder Sync extension and add Finder Filter through Finder's View → Customize Toolbar. Invoke it with the toolbar button or ⌘⇧F in Finder. Accessibility access is optional and enables copying the live expanded-folder state.

## Updates

Starting with 0.7.0, choose **Finder Filter → Check for Updates…**, or the same item under the menu bar icon. Sparkle offers automatic checks with the user's consent. Automatic installation is off by default.

Appcast: https://nearlynydev.github.io/finder-filter-releases/appcast.xml

Archives and the appcast are signed with Ed25519. Older versions without Sparkle require one manual installation.

This repository contains public release artifacts and metadata only. Application source code is not included.
